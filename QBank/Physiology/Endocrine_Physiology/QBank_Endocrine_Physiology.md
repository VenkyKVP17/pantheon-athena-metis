# Endocrine Physiology QBank

## Q1. Target Organs vs Endocrine Glands: Functional Anatomy of the Uterus
**Question ID:** Q1785415135063
**Question:** Which of the following organs is a target organ that responds to circulating hormones but does NOT function as an endocrine gland itself?
- A) Image A (Pituitary gland)
- B) Image B (Thyroid gland)
- C) Image C (Ovary)
- D) Image D (Uterus)

**Answer:** D) Image D (Uterus)

**Explanation:**
Image D represents the **Uterus**.
The uterine wall consists of three typical layers:
- **Endometrium** (inner lining) - responds dynamically to hormones (estrogen and progesterone) but does not produce them.
- **Myometrium** (thick smooth muscle layer) - provides contractile function.
- **Perimetrium** (outer serosal covering).

The uterus is a primary **target organ** that responds to hormones secreted by the ovaries (estrogen and progesterone), but does **NOT have endocrine function itself**. It does not secrete hormones into the bloodstream.

**Key Distinction:** The uterus is essential for implantation and pregnancy but is **not an endocrine gland**. It responds to hormones but doesn't produce them.

**Take Home Message:** The uterus is a hormone-responsive target organ composed of endometrium, myometrium, and perimetrium, but does not possess endocrine function or secrete hormones into the bloodstream.
