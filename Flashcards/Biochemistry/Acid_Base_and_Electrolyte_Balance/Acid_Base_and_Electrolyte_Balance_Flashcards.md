# Acid Base and Electrolyte Balance Flashcards

What is the formula to calculate expected respiratory compensation (PaCO2) in metabolic acidosis, and how is it interpreted?
?
**Winter's Formula:**
$$\text{Expected PaCO}_2 = 1.5 \times [\text{HCO}_3^-] + 8 \pm 2$$

- If measured $\text{PaCO}_2 =$ expected range: Pure **metabolic acidosis** with appropriate respiratory compensation.
- If measured $\text{PaCO}_2 >$ expected range: Superimposed **respiratory acidosis** (hypoventilation).
- If measured $\text{PaCO}_2 <$ expected range: Superimposed **respiratory alkalosis** (hyperventilation).

How is the Delta Ratio ($\Delta\text{AG}/\Delta\text{HCO}_3^-$) calculated and interpreted in mixed metabolic acid-base disorders?
?
$$\text{Delta Ratio} = \frac{\Delta\text{AG}}{\Delta\text{HCO}_3^-} = \frac{\text{Measured AG} - 12}{24 - \text{Measured HCO}_3^-}$$

- **< 0.4 - 0.8:** Mixed HAGMA + Normal Anion Gap Metabolic Acidosis (NAGMA) / Diarrhea / RTA.
- **1.0 - 1.8:** Pure High Anion Gap Metabolic Acidosis (HAGMA).
- **> 1.8 - 2.0:** Mixed HAGMA + **Metabolic Alkalosis** (e.g., DKA/Uremia + Vomiting) or pre-existing hypercapnia.
